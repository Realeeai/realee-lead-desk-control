# Scoring rubric (deterministic)

Canonical copy lives in `rules.md` §2. This file is the human-readable table.

| Signal | Points | Rule ID |
|--------|--------|---------|
| Company 50–500 emp (or 30–49 + pain + budget) | +2 | 2a |
| Named ops / RevOps / workflow pain (specific broken process) | +3 | 2b |
| Category evaluation only, no named system | +1 | 2b-lite |
| Budget / investment language | +2 | 2c |
| Decision maker (Founder, C-suite, VP) | +2 | 2d |
| Timeline ≤ 90 days | +1 | 2e |
| Vague "curious about AI" only | −2 | 2f |

**Tiers:** 8–10 HOT · 5–7 WARM · 0–4 COLD · §1 disqualifiers → DISQUALIFY

The model **adds points and cites IDs** — it does not invent a tier without arithmetic unless DISQUALIFY short-circuits.
